# Sarika Sindhu | 3D Portfolio

An immersive, scroll-driven 3D portfolio website inspired by igloo.inc. As you scroll, the camera travels through a field of ice crystals, and each section of my resume appears alongside a rotating 3D crystal.

**Live site:** [sarucodeeng1-lgtm.github.io/my-portfolio](https://sarucodeeng1-lgtm.github.io/my-portfolio/)

---

## Features

- **Scroll-driven 3D scene.** The camera flies through floating crystals while the main crystal rotates for each section.
- **Orbiting skill tags.** Two tilted rings of skill tags circle the crystal in the skills section.
- **Frosted-glass UI.** Content cards use a blurred, translucent style that matches the icy theme.
- **Falling snow.** A particle system adds depth and motion.
- **Pointer parallax.** The camera follows the mouse for a subtle 3D feel.
- **Responsive.** Layout and 3D scale adapt to phones and tablets.
- **Accessible.** Respects reduced-motion settings and falls back to a gradient if WebGL is unavailable.

## Tech Stack

- HTML5, CSS3, JavaScript
- Three.js r128 for the WebGL 3D scene
- Google Fonts (Sora)
- GitHub Pages for hosting

The whole site is a single `index.html` file with no build step.

## Run Locally

```bash
git clone https://github.com/sarucodeeng1-lgtm/my-portfolio.git
cd my-portfolio
```

Open `index.html` in a browser. An internet connection is needed because Three.js and the font load from CDNs.
